# Security policy

Mezcla captures system audio to change its volume and talks to browsers through a native messaging host and a
private Unix socket. Audio is processed in memory and never leaves the Mac.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/marcosotomac/sound-dock/security/advisories/new),
not in a public issue. Include the macOS version, the Mezcla version or commit, and steps to reproduce.

You can expect a first answer within a week. Fixes ship in a new release, and the advisory is published once
users can update.

## Supported versions

Only the latest release receives security fixes.
