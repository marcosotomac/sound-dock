# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and constructive, assume good intent, and keep discussions about the work. Harassment,
insults and personal attacks are not tolerated in issues, discussions, pull requests or any other project
space.

Report unacceptable behavior privately to the maintainer through
[a private security advisory](https://github.com/marcosotomac/sound-dock/security/advisories/new) or by contacting
[@marcosotomac](https://github.com/marcosotomac). Reports are handled confidentially, and the maintainer may
remove contributions or block participants who break these rules.
